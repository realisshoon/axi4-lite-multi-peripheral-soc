UVM 후속 검증 Evidence 대조 및 PT 수정안

검토일 2026-10-28 · 상태: 내용 수정안 / 디자인 미반영

로컬 후속 검증 코드·로그와 교육 당시 발표자료를 대조했다. GitHub URL·후속 Branch·Commit SHA·Evidence 경로 및 현재 20장 PT 링크가 입력되지 않아 업로드된 특정 커밋과의 동일성, 현재 PT 페이지별 일치 여부와 수정 페이지 번호는 미확정이다. 아래 항목은 내용 기준의 수정 후보이며 새 20장 구성이 아니다. 기존 순서·디자인을 유지하고 사용자 승인 후 반영한다.

1. 교육 당시 직접 수행한 검증과 후속 Codex 지원 검증

교육 당시 원본 검증은 사용자가 직접 수행한 활동으로 구분한다. 2026-10-19 enhancement의 자극·checker·RTL 수정 및 회귀 결과는 “교육 이후 Codex 지원 후속 검증”으로 별도 표기한다. 같은 날 보존 원본을 다시 실행한 baseline failure도 교육 당시 발생한 실패로 소급하지 않는다. CNN의 보존 결과는 enhancement의 신규 실행에 포함하지 않는다.

4. I2C ACK 판정과 기존 발표의 정합성

판정: 로컬 후속 검증의 ACK wrapper 배선 수정 및 정상 실행 근거 확보. 교육 당시 ACK sampling 수정 완료의 인과관계는 별도 미확정.

근거 단계확인 내용
수정 전 소스원본 wrapper의 master 포트가 .ack_in(master_read_ack), .ack_out(slave_ack_received)로 연결되어 있다.
수정 후 소스후속 wrapper는 .ack_in(ack_in), .ack_out(ack_out). 현재 RTL/TB 16개 파일 모두 distributed build source_manifest의 SHA-256과 일치한다.
실패 재현2026-10-19 seed 1 로그에 ACK unknown UVM_ERROR 12건. 교육 당시 12 PASS·WARNING 단계와 같은 로그가 아니다.
수정 후 실행seed 10 directed 로그: issued/completed 24, checks/pass 48, fail 0, E/F 0. metadata가 distributed build hash를 참조한다. 전체 15회 26,038 checks PASS도 재집계했다.
표현 제한Before seed 1 / After seed 10은 동일 seed A/B 실험이 아니다. 배선·monitor·stimulus가 함께 바뀌었다. ACK 관련 전체 기능 해결, 교육 당시 해당 수정을 직접 완료했다는 증거로 확장하지 않는다.

권장 문구: “교육 이후 Codex 지원 검증에서 ACK wrapper 연결을 수정하고, 수정 소스와 연결된 회귀 로그에서 정상 동작을 확인했다. Single-byte 종료는 final NACK 기준이며 ACK continuation은 미검증이다.”

기존 자료의 주장대조 결과수정 방향
SPI PASS 48 / FC 59.59%교육 원본 로그와 일치.교육 당시 결과로 유지하고 후속 10-seed 결과를 별도 추가.
I2C 초기 PASS 12 / FC 85.71% → 14 / 100%, ACK sampling 해결최종 14 / 100% 로그는 존재. 초기 실행과 수정 인과관계는 미확정. 보존 현재 소스와 과거 성공 로그도 불일치.과거 결과와 후속 wrapper 수정의 근거를 분리. 교육 당시 해결 완료 문구는 보류.
I2C waveform의 Repeated START후속 testplan은 START/STOP 단위 single-byte이며 repeated START를 검증 범위에서 제외.현재 소스·로그로 입증된 범위로 캡션 제한. 과거 파형에 실제 repeated START가 있는지는 별도 확인.
ACK sampling 원인 설명교육 발표자료는 Monitor를, 현재 GitHub README는 Driver를 지목한다. 후속 소스에서는 wrapper 연결 문제가 확인된다.원인 세 설명을 동일 사건처럼 통합하지 않음. 각 버전의 코드·로그에 맞춰 서술.
AXI FC 100%, 32 PASS, DUT 70.76 / Master 86.94 / Bus 100%32 PASS·legacy 7/7은 과거 범위. “SPI Bus”의 정확한 hierarchy 명칭은 미확정.후속 fixed_v5 43/43 및 DUT scope를 명시하고 Bus 100% 포괄 표현 보류.
로컬 PPT_CONTENT의 후속 대표 수치SPI/I2C/AXI/VGA 수치가 이번 raw-log 재집계와 일치.현재 20장 PT에 실제 들어간 값은 아직 미확인. “Team Result”를 개인 직접 수행 성과로 옮기지 않음.

실제로 읽은 발표 원문: 교육 SPI/I2C 발표자료, AXI Peripheral 발표자료 사본. SPI/I2C main README도 확인했으나 사용자가 지정하려는 후속 브랜치로 확정한 것은 아니다.

5. 기존 20장 PT에서 보완할 내용 후보

아래는 기존 해당 내용이 있는 슬라이드만 수정하는 안이다. 한 페이지에 여러 항목이 있으면 함께 반영하고, 기존에 없는 프로젝트를 새로 추가하지 않는다. 현재 PT를 받아야 최종 수정 페이지 수·번호·문장 위치를 확정할 수 있다.

표지·목차·프로젝트 배경·회로 구조·교육 당시 보드 실측 페이지는 새 Evidence 때문에 바꿀 대상으로 선정하지 않는다. 다만 후속 수치를 인용한 문구가 이미 있다면 해당 문장만 검토한다. Basic 검증은 기존 20장에 해당 내용이 있을 때만 보완한다. 새로운 페이지 추가·순서 변경·디자인 변경은 이 수정안에 포함하지 않는다.

다음 확정에 필요한 자료: GitHub URL, Branch, Commit SHA, 검증 Evidence 경로, 현재 20장 PT 링크 또는 파일. 제공 후 커밋 기준 대조와 정확한 페이지별 기존→수정 문구를 완성해 승인을 요청한다. 사용자의 사전 승인 요청에 따라 미리캔버스 디자인에는 아직 아무 변경도 하지 않았다.
